Project Content

The activity names, descriptions, categories, duration information, and sample budgets used in this project were created specifically for the Weekend Simple project.

Activity information is stored locally in data/activities.json and is displayed dynamically using JavaScript and the Fetch API.

Social Media Icons

Social media icons displayed in the footer represent YouTube, Instagram, Facebook, and TikTok.

If the icon files were downloaded from an external website, the original source and creator should be listed here before the project is submitted.

Favicon

The Weekend Simple favicon was created specifically for this project and is stored locally as images/favicon.svg.

Images

No external photographic images are currently required by the core Weekend Simple project.

Any external images added to the website before submission will be credited in this section with the source name and link.

Development Resources

The project was developed using standard HTML, CSS, and JavaScript features.

No third-party CSS frameworks, JavaScript frameworks, website templates, or site builders are used by the project.
