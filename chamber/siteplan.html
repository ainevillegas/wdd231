Site Name

Party Tray Express

The name was selected because it clearly represents a business that provides fast, convenient, and reliable party tray ordering services for families, offices, and special occasions.

Optional domain: partytrayexpress.com

Site Purpose

Party Tray Express is designed to promote a small food business that offers affordable party trays for gatherings, corporate events, birthdays, and celebrations. The website will provide menu information, tray options, prices, serving sizes, delivery details, and an online inquiry form for customers.

Scenarios

  • What party tray package is best for 20 to 30 guests?
  • Which areas are included in the delivery service?
  • How much does each party tray cost?
  • How can I place an order for my upcoming event?

Color Scheme

Teal — #008080

Used for the header, headings, links, buttons, navigation elements, and footer.

Light Coral — #FF7F50

Used for call-to-action buttons, section borders, highlights, and decorative accents.

Light Mint — #F0FFFA

Used as the page background to create a clean, light, and welcoming appearance.

Typography

Poppins will be used for the main heading, section headings, site name, navigation, and important labels.

Open Sans will be used for paragraphs, lists, descriptions, forms, and general page content.

Wireframes

The wireframes illustrate the planned responsive home page layout for Party Tray Express. The mobile layout displays the content in a single column, while the desktop layout uses a wider multi-column presentation.
